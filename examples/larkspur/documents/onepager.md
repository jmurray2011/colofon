# Before sunset

- Inspect deck markings and clear walkways.
- Confirm the emergency cabinet is sealed.
- Compare station clocks with the time service.
- Verify at least 50 GB of local storage is free.

# Weather limits

| Check | Hold when |
| --- | --- |
| Wind | Above posted access limit |
| Humidity | Condensation risk is reported |
| Lightning | Any station warning is active |
| Cloud | Target field is obscured |

# Start the session

1. Enable the laptop night profile.
2. Run `relayctl status`.
3. Open a new observation session.
4. Record the instrument and observer names.

# During observing

- Keep white lights off outside emergencies.
- Record direct observations before interpretation.
- Confirm weather data is less than five minutes old.
- Keep raw files until transfer verification.

# Transfer states

| State | Meaning |
| --- | --- |
| Local | Saved on this laptop |
| Queued | Waiting for the relay |
| Transferring | Copy in progress |
| Verified | Archive checksum confirmed |

# Close the station

- Park and cover the instrument.
- Verify all session receipts.
- Record open maintenance items.
- Return emergency equipment to its marked location.

> [!caution]
> Safety lighting overrides night-mode practice during any emergency.
